## 一、背景

用户指令（原话要点）：

1. 「把现在森空岛的『游戏数据总览』和『森空岛主站』删了」—— 两个 H5 外链项作废。
2. 「新建一个『游戏数据』来放这个 API」—— 即 `card/detail`（森空岛 App 个人主页同源，字段对照见前置文档第三节）。
3. 「我要看看到底能不能进入 H5 页面」—— 实测 H5 路径，结论见下。

## 二、实测结论：H5 能不能进（2026-11-15，内置浏览器真开）

| 项 | 结论 |
|---|---|
| 页面本身 | `https://game.skland.com/endfield/game-data?header=0` 浏览器直接打开，**不跳转、正常渲染**（React SPA，路由表还有 war-echoes / umbral-monument / crisis-contract / realtime-detail 等子路由） |
| 未登录 | 只显示「终末地 x 森空岛 · 协议终端 数据查询工具」引导页 + 二维码，**没有任何游戏数据** |
| 登录路径 | **不存在（用户实测纠正）**：墙上二维码是「下载森空岛 App」的引导，不是网页登录入口；这个 H5 对 PC 浏览器是数据死路，别再绕 |
| 独立「个人主页」路由 | **不存在**。H5 端 `endfield/game-data` 就是总览页；App 里那张个人主页与它同源，数据都出自 `card/detail` |

即：H5「能打开」但「拿不到东西」，页面自带的就是下载引导墙。数据展示走 API 直连面板，H5 链接只留在面板内当摆设。

## 二.5、模拟器 / ADB 评估（用户追问：模拟器开森空岛 / adb 调试真机能不能拿数据）

**结论：拿数据不需要，也不值得。**

- 数据链已经通了：PC 拿鹰角 token → skland API 直连，App 个人主页的全部字段（含理智、信用、干员列表）都在 `card/detail` 里，模拟器/手机拿不到任何 API 之外的东西。
- ADB 能到的只有界面层：`uiautomator dump` / 截图+OCR 可以抠数字，又慢又脆，且比现成 API 少信息（头像图、进度条等还得自己拼）。
- ADB 到不了私有数据：token/数据库在应用私有目录，无 root 读不了；`adb backup` 现代应用基本禁用。
- 模拟器 + 抓包（mitmproxy）：Android 7+ 应用默认不信任用户证书，森空岛有 SSL pinning，得过 Frida/Xposed——投入大，产出 ≈ 0（端点和签名算法早就公开且已真打）。
- 如果只是想在 PC 上**看**真实 App 页面：真机 + `scrcpy`（USB/无线 adb 镜像，零 root）是最懒的路；或模拟器（MuMu 等）装森空岛 App 登一次。这是「看」的方案，不接进宿主。
- WSA（`MustardChef/WSABuilds`）：微软官方 WSA 已停服（2025-03），WSABuilds 提供的社区构建在 Win11 上仍能装能跑，看 App 没问题——但同样只解决「看」，数据面已被 API 直连覆盖（同日真打验证，见下节），不值得为数据装它。

## 七、图标不显示排查 + 加载提速（2026-11-15 下午第二轮）

- **根因（本会话的锅）**：图标改动只同步了宿主和包仓库，**忘了 cp 到部署副本就重签了**——宿主有渲染代码，provider 还是旧模型（无 icon 字段），日历自然无图。教训：改包文件后的固定动作是「cp → sign → verify」，三步不能拆。
- 修复后从部署副本目录实测（`py -B` 防 `__pycache__` 污染）：日历 30 格 icon 全带 URL，干员行带头像，重签 `valid · PaperKito`。图标 URL 无防盗链（带/不带 Referer 均 200）。
- **加载提速两刀**：
  1. `skland.overview()` 请求并行化：binding‖teenager、card‖war‖attendance 两批并发，7 个串行 RTT → 4 个，`community-model` 全程 2.78s → 2.18s（stdlib ThreadPoolExecutor，异常经 `.result()` 正常冒泡）。
  2. 宿主 `PackCommunityPage` 通用模型缓存：上次的好模型存 `LocalFolder/gamepacks/<id>/community-model.json`，重开页面先画缓存（秒开）再后台拉新覆盖；拉新失败且有缓存画面时静默保留旧数据（InfoBar 不打断，刷新按钮手动重试）。缓存不含凭证。
- 宿主 Release 构建 0 错误（中途 16 个报错为脏 obj 瞬时抖动，rebuild 消失，符合项目口径）。

## 九、签到页实装（2026-11-15 下午，按 v4 预览）

**包侧**（全部游戏知识）：
