# 森空岛 · 国际服（GL）与国服隔离 + 账号箭头禁用（2026-11-17）

## 需求

Alpha 原话要点：

> 把国际服和国服的森空岛隔开，两个服务器不是用同一个 API。
> 国服在危机合约等地方改了显示「该内容还未开发完成」，直接把国际服打开森空岛就显示这个。
> 导航栏不用改，所有的内容都显示这个。账号登录的上下箭头改成不可交互模式。

## 结论

按宿主通用的「服务器变体码」把社区模型分流，包自己决定语义，宿主零游戏知识：

| 变体 | 社区页行为 | 森空岛请求 | 账号切换器 |
|---|---|---|---|
| `GL`（全球 / 国际服） | 左栏五项菜单**原样保留**（标题 / 图标 / 顺序 / 分割线不动），五个内容页全部只显示本地化的「该内容还未开发完成」 | **一个都不发**，不碰国服 `zonai.skland.com` 端点 | 上下箭头 + 头像入口都不可交互 |
| `CN` / `BILI`（以及不传 server 的旧调用） | 维持现状：签到与游戏数据正常，三玩法占位 | 原链路不变 | 可交互 |

「游戏数据」在 GL 下也不再打开 CN 的 H5 手机窗口：导航项视觉不动，只摘掉模型里的 `action`，点击后落到占位面板。

## 改动清单

### 包（`Arknights-Endfield`）

- `provider.py`
  - 新增 `COMMUNITY_WIP_SERVERS = {"GL"}` 与 `community_is_wip(params)`；只认宿主透传的通用 `server` 变体码，缺省按 CN 兼容旧调用。
  - `community-model`：GL 时 `unfinished` 扩为 `sign / crisis / monument / echoes / gamedata` 五项，五个面板统一 `placeholder`；`gamedata` 去掉 `action` 但保留 `separator`；返回 `accountSwitcher.enabled = false` 后**立即 return**，不进凭证校验、不调用 `skland.overview`。
  - `community-action`：GL 时所有动作（签到、H5、登录链）直接返回 `{ok:false, message:<本地化未开发提示>}`，不下发任何网络请求。
  - `credential` 块保留不动：抽卡页仍用 `community-model` 取凭证帮助文案，不受服隔离影响。

### 宿主（Arietta，通用能力）

- `src/Features/GamePacks/PackCommunityPage.xaml.cs`
  - `community-model` 请求透传 `server = pack.ServerCode`。
  - 读取通用字段 `accountSwitcher.enabled`；为 `false` 时禁用 `Button_AccountSwitcher`，并把 `Grid_Avatar.IsHitTestVisible` 设为 `false`（WinUI 的 `Grid` 没有 `IsEnabled`），`Tapped` 处理器再按箭头状态兜一层。头像与箭头是同一个浮层入口，必须一起禁，否则点头像仍可登录。
  - 导航动作 `community-action` 透传 `server`。
- `src/Features/GamePacks/PackCommunitySectionPage.xaml.cs`：面板动作透传 `server`。
- `src/Features/GamePacks/GamePackCommunityAutoSignService.cs`：自动签到动作透传 `server`；GL 若残留旧凭证也会被包侧拒绝，不会误打国服签到接口。

**新增通用协议字段**：`accountSwitcher: {enabled: bool}`（宿主只读，缺省 `true`；旧包行为不变）与请求参数 `server`（宿主已有变体码，不解释语义）。换任何游戏包、任何服务器，宿主一行都不用改 —— 符合 AGENTS.md 架构红线。

## 验证

- 包内 `provider.py / skland.py / l10n.py` 语法检查通过。
- `py -B provider.py` 单行协议探针：
  - GL / zh-Hans：五项菜单原样、五面板全是「该内容还未开发完成」、`accountSwitcher.enabled=false`、`error=null`、无 `action`。
  - GL / en + 假凭证：英文占位、仍然不发请求、开关仍为 false。
  - CN / zh-Hans：仅三玩法占位、`gamedata` 仍有 `h5-terminal` 动作、开关为 true、无凭证提示照旧。
  - GL / `community-action(signin)`：`ok=false`，消息为本地化未开发提示。
- 宿主 `dotnet build src/Arietta.csproj -c Release -t:Rebuild`：**0 错误 / 99 警告**（既有基线）。中途一次 `Grid.IsEnabled` CS1061 已改为 `IsHitTestVisible` 后全量重建通过。
- 部署副本 `Arietta/src/Arietta/games/arknights-endfield/provider.py` 已同步；`GamePackSign sign` + `verify` = **valid · PaperKito**；在部署目录直接跑 GL 探针输出与仓库一致，复核签名仍 valid。

## 注意 / 待验

- 仓库根 `signature.json` 按 AGENTS.md 约定未重签（assets 半成品收尾时统一处理），宿主实际加载的是已重签的部署副本。
- `AppConfig.LocalFolder/gamepacks/<变体 id>/community-model-*.json` 若存有旧模型缓存，首帧会先画旧内容、随即被新模型覆盖；点「刷新」立即生效。缓存是用户数据，未删除。
- GL 账号切换器禁用后，社区页无法登录；抽卡页自己的登录入口不受影响（其 `community-model` 调用不传 `server`，仍按 CN 口径拿凭证帮助文案）。
- **待 Alpha 目验**：切到「全球」→ 森空岛 → 左栏五项照旧、点任意项都只有一句未开发提示、头像右侧上下箭头点不动；切回「中国」→ 签到 / 游戏数据照常。
