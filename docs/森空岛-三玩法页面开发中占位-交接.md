# 森空岛 · 三玩法页面内容下线 + 本地化居中占位（2026-11-17）

## 需求

把森空岛「危机合约 / 影拓丰碑 / 战争回响」三个页面现在的全部内容删掉，页面中间只放一句**支持界面语言本地化**的提示。

> 用户原话写作「改内容还未开发完成」，按 `改 → 该` 的拼音笔误处理，简中定为 **「该内容还未开发完成」**。若要按原字显示，只改 `assets/l10n.json` 的 `p.panel.wip.zh-Hans` 一处即可。

## 结论

三个导航项保留（标题仍按语言翻译），三个面板的模型只剩一个 `placeholder` 字段；宿主把它渲染成内容区正中一行文字，标题 / 指标卡 / 进度块 / 外链按钮 / 说明 / 动作按钮全部不渲染。每日签到与「游戏数据（官方 H5 手机窗口）」不受影响。
