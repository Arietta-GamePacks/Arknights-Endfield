---

## 一、结论先说

| 项 | 改法 |
|---|---|
| 行头像背景 | 卡池列 6★/5★ 行的 28×28 头像 Border 原来有 `AccentFillColorDefaultBrush` 占位底色，wiki 抠像图的透明区域全露出这层强调色（总览物品卡后面是近黑的卡底，所以「总览就没有」）。**底色直接删掉**，透明区域露页面底，与总览观感一致 |
| 稀有度三色 | 6★ 红 `#FF5C5C` / 5★ 金 `#FFD751` / 4★ 紫 `#A97EE3`，原来是 6★橙 `#FFA500` / 5★紫 `#C864E0` / 4★蓝 `#5EAAED` |
| 生效范围 | ①卡池列 Segmented 页签（6★/5★ 文字色）②卡池列统计行（`s6/s5/s4` tone → 宿主 `RowBrush`）③总览物品卡 3px 品质条（原 6★金/其余紫 → 改按 quality 分三档）④`up!` 角标（绑 `PackStar6`，随 6★ 变红） |

品质条的分档：`quality >= 6` 红 / `>= 5` 金 / 其余紫。模型侧 `items[]` 只产 5/6，4★ 分支是兜底，写全了免得以后加 4★ 统计时漏改。
