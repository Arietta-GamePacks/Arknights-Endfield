# 游戏包-切换器封面与默认背景接入-交接

## 背景
把 GRYPHLINK 提取的终末地素材接入 Arietta（见 `资源-GRYPHLINK启动器封面与壁纸提取-交接.md`）：
`background.webp` 作为主页默认背景，`lang/` 下 5 张本地化封面（474×474）上游戏切换器全屏卡片。
规则：中国服务器（serverCode=CN）固定简中；国际服跟随 Arietta 界面语言。素材路径必须
对齐宿主 `GamePackAssets`（background / poster / logo）的语义，不能自造结构。

## 实测结论
- Arietta 的 `GamePackAssets`（Core/GamePack.cs）此前**只有 schema 没有消费者**：
  background/poster/logo 三个键解析后没有任何 UI 读取，`assets` 全 null 也能正常跑。
- 切换器全屏卡片对游戏包条目原本显示 `pack.icon.png`（BuildGroups 里
  `GameGroup(entry.Name, entry.GameIconPath, …)`）；鸣潮/战双的卡片字标已经是
  「按界面语言选图 + 回落英文」的模式（WuwaLogoPath/PgrLogoPath），包游戏照搬该模式即可。
- 主页背景链路在 `BackgroundGallery.GetItems/Resolve`：官方动态背景 → 用户自选背景，
  全空时 `Resolve` 返回 null 不铺图。包自带背景插在**最前**即可成为缺省回落，且出现在
  背景切换条里可被主动选中。
- 背景图库/游戏切换器都按 `GameBiz` 取数，而所有游戏包共用 `GameBiz.External`——
  所以 `GetItems/Resolve` 增加了可选的 `GameEntry` 参数，由调用方传当前条目
  （`MainView.CurrentGameEntry`），否则多个包的背景会串台。
- `Localization.UiLanguage.Current` 无 UI 依赖（config + CultureInfo），可以脱离宿主
  进程做单元自检（用 pwsh 5.1 加载不了 net10 程序集，需临时 console csproj 引用
  Arietta.dll + 拷贝 `Microsoft.WindowsAppRuntime*.dll` 到输出目录，绕过
  CloudSyncHost 的 module initializer）。

## 实现行为
### 游戏包侧（本仓库）
- `game.json` → `assets`：
  - `background`: `assets/launcher/endfield/background.webp`（主页缺省背景）；
  - `logo`: 语言映射，键与 `names` 同一套 tag（zh-Hans/zh-Hant/en/ja/ko），
    值**直接指向 `lang/<gryphlink 语言码>/cover.webp` 原封面**（474×474，含本地化
    Logo），宿主 `Image Stretch=Uniform` 等比缩放完整显示，Logo 必在。
    ⚠️ 工艺走了四版弯路（模糊垫底 → 底部裁切带 → 居中裁切带，全部被否），
    终版结论：**对切换器卡片图不做任何派生加工，包里只放官方原图，缩放交给宿主**。
    16:9 卡框两侧的空边是方图完整显示的几何必然，卡片深色底透出即为背景。
    `card/` 派生目录已删除（曾生成的模糊垫底版 / 底部裁切版 / 居中裁切版均废弃）。
  - `poster` 仍为 null（宿主未消费，留位）。
- 474×474 原始封面仍归档在 `lang/<码>/cover.webp`。
- ⚠️ 封面语言映射曾认错 3 张（繁中/英文/日文循环错位，已纠），纠错记录见
  `资源-GRYPHLINK启动器封面与壁纸提取-交接.md`；卡片随封面重生成。

### 宿主侧（Arietta 仓库，均为最小改动，全部游戏无关）
- `Core/GamePack.cs`：
  - 新增 `PackArt`（`[JsonConverter(typeof(PackArtConverter))]`）：JSON 接受单个字符串
    或 `{ 语言tag: 路径 }` 映射；`PickFor()` —— **完全跟随当前界面语言**（初版曾按
    serverCode=CN 固定 zh-Hans，实测英文界面下国服也显示中文封面，用户否决后改为跟随），
    缺语言回落 en，再回落任意一张；
  - `GamePackAssets.Logo` 类型改为 `PackArt?`（background/poster 保持 string）；
  - `LanguageTagFor` 改 public；新增 `ResolveAssetPath(相对路径→绝对路径, 不存在返回 null)`。
- `Core/GameBiz.cs`：
  - `BuildGroups`：包游戏的卡片 logo = `assets.logo.PickFor()` 解析后的绝对路径，
    包里没声明或文件缺失回落 `icon.png`；
  - `GameEntry.ShortName`：包条目原来直接回 `DisplayName`（游戏名），切换列表里
    「CN | Arknights: Endfield」错成游戏名；现按 `ServerCode` 复用内置游戏同一批
    服务器文案（CN→China Server/国服、GL→Global Server、BILI→Bilibili、KR/JP/TW 同理），
    认不出的码回落 DisplayName。
- `Features/GameSelector/GameBizIcon.cs` + `GameSelector.xaml(.cs)`：
  `GameBizDisplay` 增加 `CardWidth`（默认 192），包游戏卡片为 **108×108 方形卡**——
  方封面等比缩放正好铺满，无空隙、无裁切、Logo 完整（终版方案；此前 16:9 卡框里
  方图怎么摆都被否：留空隙 / 模糊垫底 / 底部裁切 / 居中裁切，全部推翻）。
  包素材无需再做任何派生图。
- `Features/Background/BackgroundGallery.cs`：
  - `GetItems(biz, entry = null)` 顶部插入 ⓪ 包自带背景项
    （Id=`pack_background`，IsOfficial=true 不可删，图库显示为「游戏包背景」）；
  - `Resolve(biz, entry = null)` 最终回落改为 `OfficialId ?? PackBackgroundId`
    —— 用户没选过背景时默认铺包背景。
- 调用点同步传 entry：`LauncherPage.xaml.cs` ×5（GetItems 1 + Resolve 4）、
  `MainView.xaml.cs` ×1。
- `Localization`：新增 `Background_Pack`（Lang.cs 属性 + 10 个语言表：游戏包背景 /
  Pack Background / 遊戲包背景 / ゲームパックの背景 / 게임 팩 배경 / Arrière-plan du
  pack / Pakethintergrund / Fondo del paquete / Plano de fundo do pacote /
  พื้นหลังแพ็กเกจ）。

### 同步
- 已把 `game.json` + `assets/launcher/endfield/`（封面纠错版 + card/ 5 张）同步到
  部署副本 `Arietta/src/Arietta/games/arknights-endfield/`，并已用 GamePackSign 重签
  （verify = valid · PaperKito）。仓库内签名待 assets 收尾时统一重签。
- 包根 `icon.png` 已换成带弧度的启动器应用图标（原 `app_icon_256.png`，256×256 RGBA，
  圆角外透明）：宿主 `Image Stretch=Uniform` 等比例缩放到 40×40 / 48×48 各框，
  单文件即可，无需按尺寸出多份。替换后部署副本已重签。

## 验证方式
- `dotnet build Arietta.csproj -c Release` → 0 错误（警告全为原有项）。
- 临时 console 工程（%TEMP%\packart_check）引用 `bin/x64/Debug/Arietta.dll` 跑断言，
  全部通过：
  1. `GamePack.Load(game.json)` 无 LoadError；
  2. `ResolveAssetPath(assets.background)` 指向存在的 background.webp；
  3. 包条目 `ShortName` ≠ DisplayName（CN 服命中「China Server/国服」文案）；
  4. `PickFor()`（本机系统语言 zh-CN）→ `card/zh-cn.webp` 且文件存在；
  5. 仅 `{"en": …}` 映射回落 en；仅 `{"fr": …}` 映射兜底取 fr。
- 卡片工艺肉眼验收：做「封面+卡片」九宫格对照表逐语言核对 Logo 文字（就是靠这个
  发现语言映射错的，重跑生成脚本前先看这张表）。
- 界面验收（待人工）：英文界面下切换器显示「CN | China Server」+ 英文 Logo 卡片；
  简中界面下显示「明日方舟：终末地」；主页没选过背景时铺主视觉。
