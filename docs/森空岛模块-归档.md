## 一、终态一句话

森空岛（终末地）模块 = 宿主原生 `PackCommunityPage`（NavigationView 248px + Frame），菜单五项：
**每日签到 / 危机合约 / 影拓丰碑 / 战争回响 / 游戏数据**；数据全部来自 PC 直连 Skland API（不装 App、不 root、不抓包、不模拟器、不走 H5），签到页为鸣潮（库街区）同款结构，含「立即签到」与启动器自动签到。

## 二、数据链（全部在包内 `skland.py`，宿主零游戏知识）

```
鹰角账号 token
  → POST as.hypergryph.com/user/oauth2/v2/grant {appCode: 4ca99fa6b56cc2ba, type:0}   → code
  → POST zonai.skland.com/api/v1/user/auth/generate_cred_by_code {kind:1, code}       → cred + 签名密钥
  → 签名请求（cred + sign 头）
       GET  /api/v1/game/player/binding            角色绑定 → roleId / serverId
       GET  /api/v1/user/teenager                  森空岛 userId（不是游戏 uid）
       GET  /web/v1/game/endfield/card/detail      个人主页全字段（权限等阶/探索/干员/理智/信用/合约/丰碑…）
       GET  /api/v1/game/endfield/card/war-echoes  战争回响赛季 + 当期轮换周
       GET  /web/v1/game/endfield/attendance       签到日历 + 额外奖励
       POST /web/v1/game/endfield/attendance       签到（写）；头 sk-game-role = "3_<roleId>_<serverId>"
```

- sign = `MD5( HMAC-SHA256(key=签名密钥, msg = path + query/body串 + ts + 四头紧凑JSON).hexdigest() )`；GET 用 query 原串、POST 用 body 串（无 body 用空串）；ts 回拨 5 秒；四头 `platform/timestamp/dId/vName` 值可自造但必须参与签名且与发出头一致。
- `_login` / `_signed_get` / `_signed_post` / `_binding_q` 四个内部函数承担全部链路；`overview()` 两批并行（binding‖teenager、card‖war‖attendance），7 RTT → 4 RTT（实测 2.78s → 2.18s）。

## 五、自动签到（宿主通用，`GamePackCommunityAutoSignService`）

- 触发：进程启动 + 主窗口每次显示（App.xaml.cs 两处，与库街区自动签到同挂点）。
- 范围：声明 `capabilities.communityAutoSign` 的包（终末地包 game.json 已开）；逐包判断 开关开 + 有凭证 + 当天未签。
- 记账：`GamePack_CommunityAutoSign_Last_<pack>`，**真跑出结果才写**（含官方回「已签过」按成功）；失败/异常不记账，下次触发自动补。库街区「按项记账、中断不连坐」的血泪经验照抄。
- 提示：全成功只弹「每日签到完成」；有失败才摊明细；没跑的项不报。
- 幂等：签到接口重复调用返回「今日已签到」，服务按成功处理。

## 六、关键坑（全部真打踩过）

1. `game/player/info` 只认方舟 uid；终末地必须 `card/detail` 且需 `roleId + serverId + userId`（userId 来自 teenager，不是游戏 uid）。
2. 绑定结构里终末地方舟差异：终末地有 `roles[]` / `defaultRole`，方舟 `roles` 为空。
3. **签到 `sk-game-role` 是 `3_<roleId>_<serverId>`，裸 roleId 返回 HTTP 400 参数错误**（格式来自 nonebot-plugin-skland `endfield_sign`）。
4. war-echoes 独立接口多一层 `data.warEchoes` 包装；「狂热轮换 II」就在 `seasons[].weeks[]`（按 ts 夹当前周），不在 `config.realtimeModules`。
5. `hasToday` 语义反直觉（见第四节）。
6. 图标 URL 在 `resourceInfoMap[].icon` / `charData.avatarSqUrl`，`bbs.hycdn.cn` 无防盗链；WinUI `BitmapImage` 不带 Referer 可直接加载（HTML 预览页需 `no-referrer`）。
7. 改包文件后固定三步：**cp 到部署副本 → GamePackSign sign → verify**（漏了 cp 会得到「宿主有渲染、provider 无字段」的空壳，本会话踩过一次）。
8. 按钮贴边必须放 ScrollViewer 外（Grid Row 0），塞进滚动区用负 margin 会被视口裁切。
9. 已完成态只淡内容、✓ 角标保持全亮（整格 Opacity 会把角标一起压暗到看不见）。

## 七、H5 / 模拟器结论（关闭）

- `game.skland.com/endfield/game-data` 浏览器能打开，但**只有「扫码下载 App」引导墙，无网页登录路径**——对 PC 是数据死路，已从菜单删除两个外链项（游戏数据总览 / 森空岛主站）。
- 模拟器 / WSA / 真机 ADB 只能「看」App，拿不到 API 之外的数据；抓包需过 SSL pinning，投入大产出为零。数据面已由直连覆盖，全部关闭。

## 八、验证口径

1. 协议自测（单请求单进程，stdin/stdout JSON）：`ping` capabilities 含 `community-model` / `community-action`；无凭证 → 菜单骨架 + error；假 token → error 进模型。
2. 真打：`community-model` 全字段；`community-action signin` → 签到成功 → 重复 → 今日已签到；签到后模型 `已签 N/30`、格 done、状态flip。
3. 宿主：`dotnet build src/Arietta.csproj -c Release` 0 错误（MSB3027/3021 = 实例锁 exe，杀进程重试；WMC9999 系列 = 脏 obj，rebuild.bat 清）。
4. 部署副本：`GamePackSign verify` → `valid · PaperKito`；包目录无 `__pycache__`。
5. 目验：重启 Arietta → 终末地 → 森空岛 → 五项菜单、签到页布局/图标/完成态、点立即签到弹提示并刷新。

## 十、登录框 UI 终态（2026-11-15 16:10）

三个页签的最终形态（宿主 `PackCommunityLoginDialog`，游戏语义全在包 provider）：

| 页签 | 终态 |
|---|---|
| Token 登录 | 单个输入框贴凭证；说明文案 = `登录[鹰角用户凭证](https://user.hypergryph.com)后，打开[账号信息页](https://web-api.hypergryph.com/account/info/hg)复制 content 到框内。`（宿主把 `[文案](url)` 渲染成可点超链接） |
| 账号登录 | 手机号 + 「验证码 / 密码」二选一；**页签内已无任何说明文字**（滑块、报错仍走底部灰字提示） |
| 扫码登录 | 二维码**画在对话框内**（220×220 白底托片 + 内嵌 WebView2），不再弹独立窗口；扫码后自动换 token 并关框 |

两条宿主通用能力（换任何游戏包都不用改宿主）：

1. `credential.help` 支持 Markdown 链接 `[文案](url)`；裸 URL 仍自动识别。
2. 二维码由宿主拿 `login-qrcode-create` 返回的 `url` 现算现画（本地 `qrcode.min.js`，离线可用），包侧只给 URL。

**坑（真机复现，已修）**：内嵌二维码**第一次**显示会被放大数倍、只剩左上角，点「刷新二维码」后正常。

- 根因：页面用 `window.innerWidth/innerHeight` 算尺寸，`NavigateToString` 执行时 WebView2 视口还没完成布局，报的是默认大尺寸 → 按超大尺寸画死 → 被 `overflow:hidden` 裁掉；刷新时视口已正常，所以「刷新就好了」。
- 修法：**不读视口**。像素源固定 640×640，显示靠 CSS（`aspect-ratio:1/1` + `max-width/max-height:100%` + `width/height:auto`）等比缩进容器，视口后变自动跟随。
- 验证：Edge 无头 492×125 / 570×305 / 870×605 三种视口，`img` 尺寸始终等于容器、三定位角齐全、不裁不变形。

**同批清理**：删掉包内孤儿 `assets/FatSlider.xaml`（宿主侧已移除 `DoubleRound2Converter/DoubleRound3Converter`，这份旧样式拷贝会被宿主 XAML 编译器扫到并报 `WMC0001`；包内无任何文件引用它）。仅存的 `.xaml.txt` 备份按约定移出包目录到 `../build-out/`，不进签名哈希。
