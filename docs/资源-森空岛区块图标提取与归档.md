# 森空岛区块图标 · 获取与归档

> 时间：2026-11-15 晚
> 性质：**归档**。从森空岛 H5 前端 chunk 中提取官方区块标题图标，四枚入库到包 assets。
> 前序：`docs/森空岛API-三玩法图标字段定位-交接.md`（含完整排查过程与被否决的路径）。

## 一、需求与结论

用户需要森空岛 App 个人主页各区块标题旁的黑白线条小图标（干员 / 危机合约 / 影拓丰碑 / 战争回响）。

**结论：这些图标是森空岛 H5 前端的静态资源，不在任何 API 响应里，但可以从公开 JS chunk 里直取。**

排查否决过的路径（详见前序文档）：
- `card/detail` / `war-echoes` API —— 无图标字段
- 森空岛 App base APK —— res 混淆，且业务 UI 动态下发，目标图标不在包内
- 官方 Wiki 蚀刻章 —— 只有活动封面大图
- 社区插件源码 —— 同 API，无图标

## 三、提取方式

```bash
# chunk 下载
curl -o GameData-CkCjogiM.js https://assets.skland.com/_static_assets/game-tools/GameData-CkCjogiM.js
# 按变量名抓取（脚本见 build-out/h5-icon-hunt/extract_all.py）
```

两类资源两种抓法：
- **base64 PNG**：正则 `\bNAME\s*=\s*`data:image/png;base64,([A-Za-z0-9+/=]+)`` → 直接 base64 解码落盘。
- **内联 SVG**：正则 `NAME\s*=\s*\(0,[A-Za-z_$][\w$]*\.forwardRef\)` 定位组件，取 `viewBox` + 全部 `{d:`...`}` 路径重组为独立 `.svg`。
