# 本地化 · 界面语言全量接入（2026-11-17）

## 背景

接《本地化-硬编码中文盘点-交接.md》：盘点发现画面设置（settings.cs）整页简中、game.json strings 约 24 个裸键把宿主 10 语译文打回简中、skland.py / provider.py 全部用户文案简中，且宿主 provider 协议不传语言。本次按「不做取舍、全量接入」完成：宿主注入界面语言，包内 10 语全量翻译，覆盖设置页 / 社区页 / 抽卡池列名 / 全部错误消息。

## 实测结论

- **术语来源（官方）**：终末地英文版抽卡系统 = **Headhunting**，武器池 = **Arsenal Exchange**；池类型 Chartered Headhunting（特许）/ RE-Factor Headhunting（重构）/ Basic Headhunting（基础）/ New Horizons Headhunting（启程）；社区三模式 Contingency Contract（危机合约）/ Umbral Monument（影拓丰碑）/ Echoes of War（战争回响）。来源 endfield.wiki.gg + skland.py H5 官方路由 slug（umbral-monument / war-echoes / crisis-contract）互相印证。
- **宿主语言机制**：`GamePack.LanguageTagFor` 返回 zh-Hans / zh-Hant / en / ja / ko / fr / de / es / th / pt-BR 十种 tag；`Lang.TryPackString` 查表顺序 `lang:键.tag → 键.tag → lang:键 → 裸键 → 宿主表`。宿主 LangEn 等表对 GachaLogPage_* 全键有译文（裸键覆盖是纯破坏）。
- **占位符同构**：Python `str.format` 与 C# `string.Format` 共用 `{0}{1}…`，一份 JSON 两个消费端。
- **踩坑实录**：settings.cs 最初从请求根读 `ui_lang` 一直回落简中——宿主注入的是 **params.ui_lang**，必须从 `params` 对象里取。排查手段：挪走 l10n.json 看是否暴露 id（区分旧 exe / 表缺失 / 语言未命中）。

## 实现行为

1. **宿主（通用能力，Arietta 仓库）**：`GamePackService.RunProviderAsync` 给每个 provider 请求的 params 注入 `ui_lang = GamePack.LanguageTagFor(UiLanguage.Current)`（GamePackService.cs ~L387）。键名与方法自带的 `lang`（内容语言：notice 公告语言、gacha 抽卡内容语言）互不冲突；宿主只传语言码，不含游戏语义，符合架构红线。宿主构建通过、无新告警。
2. **assets/l10n.json（新，翻译表）**：173 个 id × 10 语言。域名：`s.*` 设置页（5 组标题 + 26 行标签 + 16 枚举项 + 6 hint/描述 + 2 错误）、`k.*` 森空岛社区（错误 / 登录三通道 / 签到 / 三模式面板）、`p.*` provider（凭证链 / 公告背景 / 双通道错误 / 菜单 / 凭证帮助）、`pool.*` 池列名、共享 `err.network / yes / no / none / stage`。`_meta` 记术语来源与回落规则。游戏内语言名（简体中文/English/日本語…）是 endonym，保持原样不进表。
3. **l10n.py（新，加载器）**：`set_lang(params.ui_lang)` 设全局语言；`t(id, *args, lang=None)` 查表 当前语言 → zh-Hans → id。`lang` 显式参数给池列名用（跟抽卡内容语言走，不跟 ui_lang）。
4. **skland.py / provider.py**：全部用户可见字符串改 `l10n.t(...)`；provider `main()` 解析 params 后 `l10n.set_lang`（请求为空 / 非法 JSON 发生在解析前，维持简中兜底）。`p.reasonItem` / `p.joiner` 处理双通道错误拼接的分隔符。
5. **settings.cs**：尾部新增 `static class L10n`（读 `assets/l10n.json`，`SetLang` / `T`）；从 `params.ui_lang` 设语言；BuildModel 全部字面量换 `L10n.T`；hint 带占位符（分辨率档位 / 注册表键值模板）。exe 由 build.cmd 重编（obj 仍走 Directory.Build.props 重定向到 build-out）。
6. **game.json strings**：24 个裸键全部改为语言后缀键，129 键无一裸键。zh-Hans / zh-Hant / en / ja / ko 由包提供（en/ja/ko 用官方 Headhunting 术语；繁体为本包繁化）；**KuroBbs 十语全覆盖**（宿主通用表在此键上是鸣潮的「库街区 / Kuro BBS」，对终末地是错的）；fr/de/es/th/pt-BR 不写覆盖 → 回落宿主通用译文。
7. **gacha.py**：新增 `pool_label(kind, weapon, lang)`，活路径 `winui_model` 池列名接 `pool.*`（跟抽卡内容语言）；旧 `analyze()`（HTML 模型，ui 已空、gacha-stats 无消费端）保持原样不投资。ru/th 表内无条目自动回落简中。
8. **清理**：删 `ui/gacha.html`（game.json `"ui": {}` 后无消费端，含部署副本与根目录遗留 gacha.html）。
9. **部署副本**：game.json / provider.py / gacha.py / skland.py / l10n.py / settings-provider.exe(+pdb) / assets/l10n.json 已同步，`GamePackSign` 重签 **valid · PaperKito**。仓库包签名按惯例等 assets 半成品收尾统一重签。

## 验证方式

- `settings-provider.exe`：10 种 ui_lang 逐一喂 `settings-model`，组标题 / 画质预设枚举 / hint 全部按语言输出（en=Display/Ultra High…，ja=解像度/超高…，th/ko/fr/de/es/pt-BR 同理）；无 N 卡机器 DLSS 行不出现，测帧生成行枚举即可。
- `provider.py`：community-model（en/fr/ja 菜单 = Daily Check-in / Contingency Contract / Umbral Monument…）、community-action signin 无凭证（en "No Skland credential yet — log in first."）、未知方法（en "Unknown method: x"）。
- 部署副本：重签 verify valid；部署目录下直接跑 provider / exe 同样按语言输出（l10n.py 与 assets/l10n.json 相对包根解析）。
- game.json：129 键正则校验零裸键，tags 全部落在 10 语言集合内。
