# 游戏包-切换器字标卡片与图标-交接

## 背景
把 `D:\Work\Github\endfield_icons-main\svg` 下的终末地本地化字标 SVG 接入游戏切换器
全屏卡片（此前用 GRYPHLINK 的 474×474 封面直出，见
`游戏包-切换器封面与默认背景接入-交接.md`）。用户点名：字标黑字用黑底白字反色版，
与鸣潮/战双「纯黑底大字标」卡片同风格。

## 实测结论
- svg 库无 ImageMagick / Inkscape / rsvg-convert 可用时，**Edge 无头模式可直接栅格化
  SVG**：`msedge --headless=new --disable-gpu --user-data-dir=<临时目录>
  --window-size=W,H --default-background-color=00000000 --screenshot=<绝对路径>
  file:///<svg 绝对路径>`。SVG 以文档打开时按视口 fit（preserveAspectRatio），
  内容 bbox 需再裁紧。注意 Git Bash 里 `"$VAR\\$v.png"` 会把 `\$` 吃成字面量，
  输出路径一律用正斜杠。
- **endfield-icons 的字标是纯黑透明底**：切换器图标栏在深色窗口底上，黑字直接放会
  隐形。卡片走「黑底白字」（alpha 通道保留、颜色置白再贴黑底）；若要图标用字标，
  需垫亮底（曾做过品牌黄圆角底三角徽标，用户否决，已还原）。
- ⚠️ **icon.png 糊版事故**：定稿的圆角透明版图标（= `app_icon_256.png`，锐度拉普拉斯
  方差 4456）当时**没提交**，一次 `git checkout HEAD -- icon.png` 把它退回提交里的
  旧糊版（方差 2103，用户肉眼看出糊）。教训：**交接文档写了「已换」的文件必须尽快
  commit**；恢复文件前先确认工作区版不是未提交的定稿。

## 实现行为
- `game.json` → `assets.logo`：5 语言键（zh-Hans/zh-Hant/en/ja/ko）指向
  `assets/launcher/endfield/logo/<lang>.png`（960×540 黑底白字，字标统一占卡宽
  84% 居中）。宿主按界面语言挑图、缺语言回落 en，逻辑无改动。
- **zh-Hant 无繁体字标源文件**（svg 库只有 zh/en/ja/ko），暂用简中版顶着。
- 原 `card/` 5 张 474×474 封面卡已无引用，连同部署副本一起删除；原始封面仍在
  `lang/<码>/cover.webp`。
- 包根 `icon.png` 用 `assets/launcher/endfield/app_icon_256.png` 覆盖（256×256
  RGBA、圆角外透明，40×40 / 48×48 各框单文件通用）。
- 版本 1.0.0 → 1.0.1；仓库包目录与部署副本均已重签（GamePackSign, PaperKito）。

## 验证方式
- 启动 Arietta 展开切换器：全屏卡片按界面语言显示黑底白字字标（简中「明日方舟：
  终末地」等），图标栏 / hover 为圆角佩丽卡图标，无糊感。
- 签名 verify：`dotnet run --project tools/GamePackSign -- verify <包目录>`。
