# 资源-森空岛工具箱图标-交接

## 背景
社区面板（`ui/community.html`，当前为占位）计划加入「工具箱」入口，需要森空岛终末地页
（https://www.skland.com/game/endfield?cateId=16 ）侧栏工具箱里的全部图标。
已抓取并落盘到 `assets/toolbox/`，文件名 = 工具中文名。

## 实测结论
- 页面是 SPA 壳，数据接口为 `zonai.skland.com/web/v1/bulletins/list?gameId=3&cateId=16`，
  但裸 curl 和页面内裸 fetch 都返回 `{code:10000 请求异常}`——该站 web API 要自带签名头，
  没有公开签名逻辑，别再走接口路线。
- 可行路线：浏览器渲染后直接从 DOM 抓工具箱区块的 `<a><img>`（外链 + img src）。
  工具箱条目特征：href 指向 game/act/event/wiki.skland.com、endfield.hypergryph.com、tmall 等。
- 图标 CDN 在 `bbs.hycdn.cn/image/...`，下载无需鉴权（带普通 UA + Referer 即可）。
- 同页还有「下载/云玩横幅」图（text 为空），不是工具箱图标，未采集。

## 验证方式
- `file assets/toolbox/*.png` 应全部为 `PNG image data, 120 x 120, 8-bit/color RGBA`。
- 抽查打开 `每日签到.png`（日历+对勾）、`配队工具.png`（队伍图形），均为黄黑终末地风格实图。
