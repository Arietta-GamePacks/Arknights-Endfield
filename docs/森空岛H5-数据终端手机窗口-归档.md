## 一、终态一句话

「游戏数据」导航项**不再渲染 WinUI 面板**，点击直接弹手机比例独立窗口（宿主通用 `PackWebWindow`，620×1140 物理px）装官方 H5
`https://game.skland.com/endfield/game-data?header=0`——库洛数据终端（鸣潮/战双）同款三件套在森空岛侧的复刻：
**App UA + 伪造 SK 桥 + 注 cred**；cred 由包内 `_login` 现算，签名/会话 token 由 H5 自己向 `zonai /web/v1/auth/refresh` 换取，宿主与包侧都不代签。

逆向对象：`game.skland.com/endfield/game-data?header=0`（React SPA）。bundle 在

### 2.1 流程判定（页面 `getSystemInfo`）

| 判定 | 依据 | 我们的喂法 |
|---|---|---|
| `IS_APP` | UA 含 `SCHEMA_NAME`（国服=`skland`，国际=`skport`；`IS_ABROAD` 按 `location.host` ∈ {skport.com, gryphline.com, gryphline.net} 判定，game.skland.com 恒 false） | UA 里带 `skland/2.4.0` |
| `APP_VERSION` | UA 正则 `skland/([\d|.]+)` | `2.4.0`——**必须 ≥ 桥目标最低版本门**（`SKEnvironment_environmentInfo` 2.0.0 / `openAuthenticationPage` 1.28.0；页面用 `canIUse` 比版本，不够就拒绝调桥） |
| `IS_ANDROID` | UA 含 `android` | UA 是 Android 手机 UA → 选 `AndroidNative` 桥 |
| `IS_PC` | `try{IS_PC=!document.createEvent('TouchEvent')}catch{IS_PC=!0}` | **桌面内核必抛**（实测 `The provided event type ('TouchEvent') is invalid`）→ 需垫 `document.createEvent` shim，否则页面走 PC 紧凑布局 |
| 布局 | `getCommonInfo`：`IS_APP && (isHeader=false)` | App 流强制无页头——但子页 `Header` 组件不受它管，照渲染（见 2.3） |

### 2.2 桥协议（`AndroidNative` + `ABaseNative`）

```
页面调：window.<SK目标>.<method>(params, callbackId)
        - 目标全集：SKPage / SKEnvironment / SKNavigation / SKModal / SKMessage /
          SKHandle / SKShare / SKPermission / SKNetwork / SKGame（缺了抛 no bridge api）
        - params：对象会被 AndroidNative JSON.stringify 成字符串；字符串原样；可空
        - 第二参是 callbackId **字符串**，不是函数！
应答回：window.skland.callBack(callbackId, JSON字符串)      ← ABaseNative 构造时注册的原生回调通道
        页面侧 JSON.parse（code 会转 Number）→ resolve；15 秒不回 → bridge.call timeout
```

- 三个 handler 有**固定 callbackId**（`callbackIdMap` 预置）：`SKPage_lifeCycle` / `SKMessage_register` / `SKMessage_unregister`——重复调用会覆盖 callbackMap 同键条目，应答处理无影响。
- `SKPage.userInfo` → `{code:0, cred}`，页面**只取 cred 一个字段**塞进所有请求头。
- 页面自查 `canIUse(名, 静默?)` 才调桥；超时 15s（`CALL_TIMEOUT`）。

### 2.3 布局与 `SKPage.pageInfo`（四打踩坑重灾区）

- `getPageInfo`：拿到 `code==0` 后 **`top = Math.max(top, status_bar_height)`**（`is_home_page` 时再加 `navigation_bar_height`）→ `devicePxToRebasedPx` 除以 devicePixelRatio。
- **字段缺一个就是 NaN**：我们的空 `{code:0}` 让 `Math.max(undefined, undefined) = NaN` → NaN 样式被 React 丢弃 → 粘性标签栏与 Header（`Wrapper$52 $height:44 $paddingTop:{top}`）全部塌到同一位置叠住。**修法 = 按页面自己的 web 兜底形状完整应答**（`init_web$8`：`screen_width/innerWidth, screen_height/innerHeight, has_navigation_bar:false, navigation_bar_height:0, status_bar_height:0, top:0, left:0, bottom:0, right:0`）。
- `Header` 组件（子页标题栏，左返回箭头 + 中标题 + 右图标）**不读 `getCommonInfo.isHeader`**，App 流照渲染；返回箭头点击走 `SKPage.pop`。
- 页面自己的 web 兜底 `pageInfo` 就是全零字段——独立浏览器能正常渲染子页，靠的就是这个形状。

### 2.4 跳转语义（`SKNavigation`，四打踩坑）

- `schema$2`：http(s) 网址 → 包成 **`skland://web?url=<encodeURIComponent(url)>`** → `SKNavigation.dispatch`（**参数是字符串**，iOS 才包 `{schema}` 对象）；已是深链原样传。真 App 收到后推内嵌子页。
- `SKNavigation.openURL`：参数是 `{url}` 对象（到桥层已被 JSON 字符串化）。
- 「全部 / 更多 / 详情」这类入口在 App 流里**不走页面内路由，全走桥**——假桥不实现跳转 = 死点击。
- `SKPage.pop`（子页返回箭头）→ App 里是关掉推入页。

### 2.5 签名 / 会话

页面在 JS 里自己算四头签名（md5 + hmac + SHA256，`dId`/`vName` 自理），会话 token 从 cred 换、401(code 10000) 时自动打 `zonai /web/v1/auth/refresh` 续期。**宿主只需喂 cred，其余自理**——cred 与 `skland.overview()` 同源（`_login`），数据端点也同源（zonai `/web/v1/...`）。

| 轮 | 现象 | 根因 | 修复 |

## 五、假桥设计守则（从坑里提炼，换游戏包复用时照查）

1. **第二参是 callbackId 字符串**，应答走 `window.<schema>.callBack(id, JSON串)`；别等函数回调。
2. **每个 handler 都要回字段完整的应答**：页面拿 `code==0` 之后会解构字段做数值运算，`undefined` → NaN → 样式被 React 静默丢弃 → 元素叠放/错位，且无任何报错。对照页面自己的 web 兜底形状（`init_web$*` 系列）抄最稳。
3. **环境判定有依赖 DOM 能力的**（`createEvent('TouchEvent')`），桌面内核缺什么垫什么，垫层必须在页面脚本之前（`AddScriptToExecuteOnDocumentCreated` 天然满足）。
4. **UA 版本号 ≥ 桥目标最低版本门**；版本从 UA 提取参与 `canIUse` 灰度，给少了页面直接不调桥。
5. **跳转语义要么实现要么显式 no-op**：`dispatch`/`openURL`/`pop` 这类入口在 App 流不走路由；同源整页跳是懒人最优解（注入脚本随文档重装，登录态不掉），外域 `window.open` 交给宿主的 NewWindowRequested。
6. **排查通道先埋**：`window.onerror`/`unhandledrejection` → `postMessage('__packweb: …')` → 宿主日志。六轮排查全靠它 + bundle 精读，没白屏猜过一次。

## 八、已知边界与待办

1. **App 专属弹层不出现**：`SKModal.alert` 类由 App 渲染的确认框，假桥回 `{code:0}` 意味着相关流程（如确认类操作）无 UI。遇到了按第五节守则补语义。
2. **窗口无返回/刷新按钮**：H5 自带导航（顶部返回箭头已接 `history.back`）；右键菜单可刷新；再点导航项 = 带新参数重载。
3. **cred 现算**：每次点击 grant + generate_cred_by_code 两 RTT（≈1s），未做缓存；要省再加。
4. **数据新鲜度**：窗口开着期间页面不自动刷新（页面自身有 401 续期，但不会主动拉新）；再点导航项或右键刷新即可。用户已知悉并接受。
5. **H5 改版维护点**：全部集中在 `skland.py::web_terminal` 一处（UA 版本门、桥应答、pageInfo 形状、跳转语义）；宿主 `PackWebWindow` 是通用件，H5 改版不用动。
6. **仓库 `signature.json`**：按既有口径等 assets 收尾统一重签；部署副本当前 `valid · PaperKito`。
7. 并行会话曾在 `src/Arietta/log/` 丢反编译转储炸过编译——csproj 已根治（log 目录永不参与编译），转储文件本身未动。
