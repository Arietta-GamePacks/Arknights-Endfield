## 二、包目录

```
<数据目录>/games/arknights-endfield/
  game.json        清单：id / names / vendor / version / exeNames / markerDirs /
                   launch / capabilities / assets / icons / ui / provider / strings / settings / update
  signature.json   作者 + 公钥 + 签名（对包内所有文件 sha256 排序后签）
  icon.png
  provider.py      数据源进程（一次调用一个进程：stdin 一行 → stdout 一行 → 退出）

  icons/           逐条图片，文件名 = 记录里的 id
  assets/          背景 / 海报 / 字标
```

`game.json` 只描述，不承载逻辑；代码在 `provider.py`，UI 在 `ui/`，资源在 `icons/` `assets/`。

## 四、启动绕过的机制（结论，别忘）

1. `Endfield.exe` 清单 `requireAdministrator`，非提权 `CreateProcess` 直接 740；
2. 客户端要求直接父进程是**鹰角签名的 `Games.exe`**；
3. 做法：把游戏目录里的 `PlatformProcess.exe`（asInvoker、同证书）复制成 `parent/<pid>/<guid>/Games.exe`，`CREATE_SUSPENDED` 起、**永不恢复**，作为 `PROC_THREAD_ATTRIBUTE_PARENT_PROCESS` 拉起游戏；游戏退出后终止替身并删目录；
4. 因为要提权，宿主用 `Arietta.exe launchpack …` 自我重启一次（`Verb=runas`），不引入额外 exe；
5. 实测日志：`Game started gamePid=5948 decoyPid=14704`，游戏确实起来了。

## 六、命令

```bash
dotnet build src/Arietta.csproj -c Release
dotnet run --project tools/GamePackSign -- keygen .keys/endfield.key
dotnet run --project tools/GamePackSign -- sign   src/Arietta/games/arknights-endfield .keys/endfield.key "PaperKito"
dotnet run --project tools/GamePackSign -- verify src/Arietta/games/arknights-endfield
```

私钥在 `.keys/endfield.key`（已 gitignore，**不要进仓库、不要贴进文档**）。改完包里任何文件都要重新 `sign`，否则列表会显示「未签名（本地修改）」。

- 索引只存元数据，不存游戏资源；

- 托管建议 GitHub Pages（带 CORS、不吃 API 限额），索引地址在宿主侧做成可配置、允许多源。
