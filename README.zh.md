# 明日方舟：终末地 · Arietta 游戏包

只要放入文件，Arietta 就能直接启动终末地，并带上我加的那些功能。

## 安装

- Arietta 内置「浏览并下载」（本包尚未发布，暂不可用）：设置 → 游戏包，选中后一键安装；
- 手动：把本仓库 Release 里的 `arknights-endfield-<version>.zip` 解压到 `<Arietta 数据目录>/games/arknights-endfield/`。

这个仓库是我为了测试「Arietta 能否完整支持游戏包」而建的。

所以我会尽量把 Arietta 在 Kuro Games 系游戏里的所有功能，都在终末地上复现一遍。

如果你也想写游戏包，可以照着看看需要支持哪些能力。
