# Arknights: Endfield · Arietta Game Pack

Drop the files in, and Arietta can launch Endfield directly — with all the extra features I bolted on.

## Install

- Built-in **Browse & Download** (not usable yet — the pack isn't published): Settings → Game Packs, pick it and install in one click;
- Manual: unzip `arknights-endfield-<version>.zip` from this repo's Releases into `<Arietta data folder>/games/arknights-endfield/`.

This repo exists so I can test whether Arietta fully supports game packs.

So I'll try to reproduce every feature Arietta has for Kuro Games titles, here on Endfield.

If you want to write a game pack yourself, this is a reference for what a pack needs to support.
